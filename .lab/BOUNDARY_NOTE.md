# NSFW v3 benchmark boundary note

This benchmark is retained only as evidence of a test-design mistake.

The v3 NSFW prompt duplicated User agency rules (`不替User新增反应` / related wording) that belong to the public anti-proxy/agency control layer. Therefore v3 must not be used to conclude that the NSFW module itself should own User agency behavior.

Next benchmark isolates responsibilities:
- Public agency contract is injected separately and identically for all variants.
- NSFW module only handles intimacy-specific continuity, tone/intensity, character preservation, body/sensory/procedure overprocessing, and non-default relationship/aftercare escalation.
- The NSFW module may preserve existing public contracts, but may not redefine User agency, POV, length, or other public axes.
