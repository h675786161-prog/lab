# 赛哈姆运输车辆离场守卫修补

本目录只完成第一节点：修正明确载着赛哈姆实际驶离中央庭的叙述漏判并做守卫回归。修补基于交付修订1.0.2固定源码46c062a370c76b49ed530020e5aface03720162b；正式候选卡及其附件未被覆盖。小手机源代码未改，实验酒馆与小手机主分支均不合并。

## 修补与边界

同一句非对白叙述需要明确车辆搭载赛哈姆并已驶离整个中央庭。拒绝车辆空驶、人物仅在车旁、人物行李、准备或将要离场、回忆、传闻、选项、否定、仅移出主廊或门口，以及随后仍留在中央庭的矛盾叙述。已有独白前置条件及整块旗标写入保护保持不变。

守卫只过滤模型已经提出的命令，不自动补旗标、不直接修改MVU、不消耗剧情资源。车辆并非剧情必须使用的交通工具，也不是新增剧情设定；这条识别仅处理实际失败正文中已有的运输车表述。文字识别是保守启发式，不能宣称覆盖全部自然语言。
