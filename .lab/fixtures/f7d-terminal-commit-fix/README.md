本目录为隔离候选修补与测试，不替换正式交付附件，不含小手机代码。

提供者唯一实现改动：从消息正文剔除状态栏标签后，再剔除尾部空白。固定 MVU 在真实写入前追加两行换行与状态栏标签，原签名保留两行换行，导致同一消息的有效事务被取消。具体实机诊断仍以结果文件为准。

保留完整消息对象身份、正文内部字符与换行、消息数量、聊天、角色、群组、分支和失效代数校验。任何真实编辑事件（即使只编辑尾部空白）仍立即使旧事务失效；不删除提交保护，不补写剧情值，不改变接口版本或写入流程。
