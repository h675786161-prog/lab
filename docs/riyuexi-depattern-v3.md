# 日月西 v0.4 去套路校准 LAB v3

目标不是把日月西改成另一份预设，而是保留其模块化、人物活化和日月西自身气质，同时拆掉普通 RP 默认触发的“精密创作流水线”。

## 根因

原版已经有很强的反八股/去惯性规则，但同时默认存在更具体、更靠近输出端的模板生成器：

- 对话特化要求固定占比，且每段对白都承担推进/错位/塑造功能。
- 世界、人物、文风 COT 每轮都要求长篇逐项分析。
- 默认开启经验叙事（拉波夫）蓝图，普通回合也要定向、触发、展开、评议、结果、回扣。
- 创作检测在正文前、中、后多次强制自检，并把结尾限制为对白收束或微动作定格。
- Gemini 尾部要求 Ecot 每个 Vol 最少 500 tokens / 300 汉字，导致普通生活片段也先开完整编剧会议。
- 大型世界、主线规划、前文回扣、插叙、平行事件、空镜、额外文风素材默认同时开启，持续给模型“本轮必须做点写作行为”的压力。

核心判断：不是反套路规则不够，而是更深层的执行链仍在奖励结构完整、意义明确、每句有用。

## v1

第一刀只拆公共流水线：

- 对话取消固定比例与“句句有功能”。
- 情感浓郁/喜剧幽默取消 +40% / +20% 的机械加码。
- 世界/人物/文风 COT 改轻量。
- 经验叙事改为自然续场。
- 创作检测取消正文中途两次打断与固定二选一结尾。
- 11 Vol Ecot 压缩，Gemini 尾部取消每 Vol 最低长度。
- 大型世界、主线规划、前文回扣、插叙、平行事件、空镜、额外素材默认关闭。

首轮 real SillyTavern + GG A/B 显示：原版 Ecot 约 2273/2612 字符，v1 约 296/522；解释句、微动作套餐、关系词、强行钩子明显下降。

但人工读文发现 v1 为了制造“生活感”，会偷补 user 的昨夜经历、工作、身体状态、饮食偏好等未建立事实。

## v2

第二刀加入事实边界：

- user 未给出的私人事实保持未定义。
- NPC 可以问、猜、猜错，但不能把猜测升级成既定事实。
- 禁止用“生活感”作为补 user 背景的理由。
- 尝试禁止 Ecot 预演动作顺序和停笔点。

结果：user 假记忆明显减少，但模型仍会为了“生活丰富”在 NPC/环境侧主动撒大量真实性素材；Ecot 也仍有轻微动作提纲倾向。

注意：添加 v2 fixture 时，旧 v1 workflow 的 `fixtures/riyuexi-depattern/**` 路径监听误触发，导致 v1 与 v2 workflow 曾同时进入 GG 阶段。该轮结果只作文本观察，不作为 RPM 合规验收。之后所有 Riyuexi workflow 已改为 manual-only。

## v3

最终策略：不再制造“自然续场”这个第六种叙事蓝图。

- 默认关闭叙事蓝图④，并恢复其原始内容，保留为用户可选玩法。
- Ecot 只保留：边界、当前事实、输出协议三层。
- 禁止在 Ecot 中预演正文、列动作顺序、设计情绪弧、设计停笔点、分析“本轮意义”。
- 世界允许自由生长，但新细节必须从眼前动作/职业/现实因果自然长出；不为了烟火气主动撒小故障、小往事、小任务、小新闻。
- 人物核心与关系惯性直接继承，不再每轮重新证明。
- 继续保持 user 私人事实密封。
