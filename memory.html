MEMORY

角色忘事、事实打架、伏笔找不到，就来翻记忆。

这里不是让你“存得越多越好”，而是帮世界把已经发生过的东西守住。

你什么时候会来这里？

角色把已经发生的事说反了、某个关键物件死而复生、或者你突然想找几十轮以前埋过的伏笔。

✦直接戳图看发光点只解释你真正会用到的地方
你现在看到的是

最常用

先搜关键词

比如直接搜“鹤纹火漆”或“北站”。长篇时比从第一条翻到最后一条轻松得多。

发现冲突

优先修旧事实，不要叠一条新矛盾

“信已烧毁”后来如果状态改变，应该让事实更新，而不是同时留下“还在”和“已烧毁”。

没有出现正文

不等于它被忘了

后台保留一件事，和这一轮要不要把它写进正文，是两件不同的事。

还是那封信

十几轮以后，记忆应该还能告诉你：它已经烧掉了。

如果剧情重新谈到鹤纹火漆，可以继续查来源、查谁见过它，但不应该突然让原件重新出现在伊芙手里。

什么时候才手动加记忆？

明确发生过的重要事情漏掉了，或者你要修正一条错误事实时。别把它当日记本，每句对白都往里塞。
